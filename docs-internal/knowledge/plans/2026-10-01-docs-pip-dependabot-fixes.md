# Fix 43 critical/high Dependabot pip alerts in the Sphinx docs lockfile

- **Date:** 2026-10-01
- **Author:** praveen
- **Related PR(s):** TBD
- **Related issue(s) / JIRA:** [NO-JIRA] — ROCm/device-metrics-exporter Dependabot (pip ecosystem, critical+high)

## Context

All 43 open critical/high pip Dependabot alerts on the public mirror
(`ROCm/device-metrics-exporter`) are confined to a single file,
`docs/sphinx/requirements.txt` — the Sphinx documentation build lockfile
consumed by ReadTheDocs (`.readthedocs.yaml`) and `make docs`. None of these
packages ship in the runtime container or any Go binary, so runtime exposure is
zero; the alerts fire because the lockfile is committed and stale.

The file is autogenerated by `pip-compile` from `requirements.in`, which
directly declares only `rocm-docs-core[llms]` and `sphinx-reredirects`. Every
vulnerable package is a transitive dependency. The 43 alerts collapse to 6
packages needing a bump:

| Package | Was | Now | Alerts |
|---|---|---|---|
| gitpython | 3.1.43 | 3.2.0 | 24 |
| urllib3 | 2.2.3 | 2.8.0 | 6 |
| pyjwt[crypto] | 2.10.1 | 2.15.1 | 5 |
| cryptography | 44.0.0 | 50.0.2 | 4 |
| tornado | 6.5.8 | 6.5.10 | 2 |
| soupsieve | 2.6 | 2.10 | 2 |

The pensando and ROCm lockfiles had drifted apart (pensando was on
`rocm-docs-core==1.20.1`; ROCm on `rocm-docs-core[llms]==1.38.0` with the
jupyter/myst-nb stack). The fix is authored here and auto-cherry-picked to the
ROCm mirror, so the two must converge.

## Approach

1. Bring `docs/sphinx/requirements.in` to the ROCm baseline
   (`rocm-docs-core[llms]==1.38.0`, `sphinx-reredirects`) and add exact-pin
   floors for the 6 vulnerable transitive packages.
2. Seed `requirements.txt` with the ROCm baseline, then regenerate with
   `pip-compile` under Python 3.10 (matching `.readthedocs.yaml`). Anchoring to
   the ROCm baseline keeps the diff to only the 6 pins plus the two transitives
   they force (`cffi` 1.17.1 -> 2.1.1, `typing-extensions` 4.12.2 -> 4.16.0).

## Testing

- `pip install -r docs/sphinx/requirements.txt` resolves and installs cleanly on
  Python 3.10.
- `sphinx-build -b html docs` produces `index.html` with the new lockfile.

## Risks / Limitations

- Largest bump is `cryptography` 44 -> 50 (major), used only by the docs
  toolchain; covered by the docs-build check above.
- One-PR structure (baseline sync + security fix together): the `requirements.in`
  baseline change will conflict on the ROCm cherry-pick because ROCm is already
  at `1.38.0`. The `requirements.txt` portion applies cleanly; the `.in` conflict
  is resolved by taking the incoming floor lines.
