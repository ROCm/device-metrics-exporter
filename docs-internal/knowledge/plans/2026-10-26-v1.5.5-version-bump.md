## Context

release/v1.5.4 has been cut on both pensando and ROCm repos. Main needs to
move forward to v1.5.5 so that builds from main are distinguishable from the
release branch.

## Approach

- Run `hack/bump-version.sh v1.5.5` to update version strings across Makefile,
  Dockerfiles, helm charts, and docs (17 files).
- Remove release-notes TODO placeholders inserted by the script.
- ROCm tarball stays at 10.1.0 GA on main; the 10.2.0rc0 bump is
  release/v1.5.4-only.

## Scope

- **In scope:** PROJECT_VERSION, Dockerfile labels, helm chart version/appVersion,
  docs version references, release notes placeholder.
- **Out of scope:** ROCm tarball bump, gpuagent bump, any code changes.

## Validation

- `hack/bump-version.sh v1.5.5` output confirms all 17 files touched.
- `grep -r 'v1\.5\.4'` across bumped files returns zero hits.
